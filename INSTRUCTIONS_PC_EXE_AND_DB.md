# 📘 Инструкция: Работа базы данных `pc_offline_history.db`, фоновой службы и компиляция `hosts_blocker.py` в `.exe` (KidsGuard Pro v3.3.4+)

Данная памятка подробно объясняет, как устроено автономное хранение истории на компьютере ребёнка (Windows 10 / 11), где именно создаётся файл базы данных SQLite, как взаимодействуют системная служба и пользовательская сессия через Планировщик заданий Windows, и как правильно скомпилировать `hosts_blocker.py` в единый исполняемый файл `hosts_blocker.exe`.

---

## 1. Нужно ли создавать базу данных `pc_offline_history.db` вручную?

**Нет, вручную создавать ничего не нужно.**  
Скрипт `hosts_blocker.py` (и скомпилированный из него `hosts_blocker.exe`) **сам автоматически создаёт и папку, и файл базы данных SQLite** в первую же секунду после запуска при помощи встроенного в Python системного модуля `sqlite3`.

### 📍 Точный путь к файлу базы данных и логам на ПК:
```text
C:\Users\Public\HostsBlocker\pc_offline_history.db
```
*(В проводнике Windows на русском языке папка `C:\Users\Public` может отображаться как `C:\Пользователи\Общие\HostsBlocker`).*

В этой же папке `C:\Users\Public\HostsBlocker\` программа автоматически создаёт и хранит:
1. **`pc_offline_history.db`** — локальная база данных SQLite с таблицами:
   - `pc_offline_activity` — история открытых программ, заголовков окон и посещённых вкладок браузеров (с отметкой времени и флагом `is_synced`);
   - `pc_offline_screenshots` — сжатые JPEG-скриншоты рабочего стола в формате Base64 (с отметкой времени, именем активного окна и флагом `is_synced`);
   - `pc_offline_meta` — служебные метаданные состояния синхронизации.
2. **`config.json`** — сохранённый список заблокированных сайтов, статус блокировки интернета (`internet_locked`), лимит времени и код сопряжения (`pairing_code`).
3. **`latest_screen.json`** — мгновенный буфер последнего захваченного кадра экрана от воркера пользовательской сессии.
4. **`blocker.log`** — журнал работы программы и сетевой синхронизации.

## 2. Почему используется именно папка `C:\Users\Public\HostsBlocker`?

Когда вы устанавливаете защиту на ПК ребёнка, программа запускает **два взаимодействующих процесса** через Планировщик заданий Windows (`Task Scheduler`):

1. **`WindowsHostsGuardDaemon` (`hosts_blocker.exe --daemon`)** — работает от имени **`СИСТЕМА` (`NT AUTHORITY\SYSTEM`)** в фоновом режиме (`Session 0`).
   - Отвечает за редактирование системного файла `C:\Windows\System32\drivers\etc\hosts`, очистку DNS-кэша (`ipconfig /flushdns`), блокировку интернета через Windows Firewall (`netsh advfirewall`), приём команд от родителя по P2P/LAN и отправку накопленной оффлайн-истории из `pc_offline_history.db`.
2. **`WindowsHostsGuardCapture` (`hosts_blocker.exe --capture-worker`)** — работает в **интерактивной сессии вошедшего пользователя** (`Session 1+`), где отрисовывается реальный рабочий стол, окна игр и браузеров.
   - Отвечает за захват живого видеопотока экрана в реальном времени (через `pyautogui` / `Pillow ImageGrab`) и определение заголовка активного окна (`GetForegroundWindow`).

> **Важно:** Если бы программа использовала относительный путь или папку `%APPDATA%`, то у учётной записи `SYSTEM` и у учётной записи ребёнка были бы две разные папки, и фоновый сервис не увидел бы скриншоты рабочего стола.  
> Благодаря жёстко заданному общему пути **`C:\Users\Public\HostsBlocker\pc_offline_history.db`** оба процесса работают с **одной и той же базой данных** без конфликтов прав доступа (включён режим `PRAGMA journal_mode=WAL`).

## 3. Как работает оффлайн-накопление (Store-and-Forward) и синхронизация с родителем?

1. **Когда родитель НЕ в сети (оффлайн) или телефон родителя выключен:**
   - Каждые 10 секунд изменение активного окна/программы и периодические снимки экрана записываются в таблицу `pc_offline_history.db` с пометкой `is_synced = 0`.
   - Чтобы база не занимала много места на диске, автоматически действует ротация (хранятся последние 500 записей активности и последние 60 оффлайн-снимков экрана).
2. **Когда телефон родителя появляется в сети (Wi-Fi LAN или глобальный P2P-канал):**
   - Фоновый демон автоматически обнаруживает подключение родителя (или получает пакет `REQUEST_OFFLINE_SYNC`).
   - Программа выбирает из `pc_offline_history.db` все неотправленные записи (`WHERE is_synced = 0`), упаковывает их в пакет `OFFLINE_HISTORY_BUNDLE` и пересылает на телефон родителя.
   - После успешной отправки записи помечаются как `is_synced = 1`, а родитель видит всю историю активности и скриншоты ПК за время своего отсутствия.

## 4. Как скомпилировать `hosts_blocker.py` в один `.exe` файл

### Шаг 1. Установка необходимых библиотек Python
Откройте командную строку (`cmd` или `PowerShell`) на компьютере, где установлен Python 3.9+, и выполните:

```bat
pip install pyautogui pillow pyinstaller
```
*(Модули `sqlite3`, `ctypes`, `socket`, `http.server`, `urllib`, `json` уже встроены в стандартный Python и не требуют установки).*

### Шаг 2. Сборка `.exe` файла через PyInstaller
Перейдите в папку со скриптом `hosts_blocker.py` и выполните команду:

```bat
pyinstaller --noconsole --onefile --uac-admin --name hosts_blocker hosts_blocker.py
```

**Что означают параметры:**
- `--onefile` — упаковывает Python, `pyautogui`, `Pillow` и сам скрипт в один независимый файл `hosts_blocker.exe` (появится в папке `dist\hosts_blocker.exe`).
- `--noconsole` — скрывает чёрное окно консоли при работе в фоне.
- `--uac-admin` — автоматически запрашивает права Администратора при первом запуске, чтобы программа могла прописать себя в Планировщик заданий Windows и защитить файл `hosts`.

---

## 5. Установка и проверка на ПК ребёнка

1. Скопируйте готовый файл `dist\hosts_blocker.exe` на компьютер ребёнка (например, в `C:\Users\Public\HostsBlocker\hosts_blocker.exe`).
2. Запустите `hosts_blocker.exe` **от имени Администратора** (достаточно одного раза):
   - Откроется окно управления (или выполните `hosts_blocker.exe --install-service` для тихой установки).
   - Программа автоматически создаст папку `C:\Users\Public\HostsBlocker\`, базу `pc_offline_history.db` и зарегистрирует две задачи в Планировщике заданий Windows (`WindowsHostsGuardDaemon` и `WindowsHostsGuardCapture`).
3. После этого даже после перезагрузки компьютера защита, перехват сайтов, запись оффлайн-истории и видеостриминг экрана в панель родителя будут запускаться **полностью автоматически**.
