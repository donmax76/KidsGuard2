====================================================================
KidsGuard Pro v3.3.35 Pro.80 — Комплект для Windows
====================================================================

В этом архиве находятся файлы для двух программ Windows:
1. hosts_blocker.py (v5.7)     — агент для компьютера ребёнка
   (отслеживает программы, окна и реальные посещённые сайты Chrome,
    Edge, Яндекс.Браузер, Opera/GX, Brave, Vivaldi, Firefox;
    блокировка сайтов/игр/ПК, чат с родителем).
2. kidsguard_parent.py (v1.1)  — программа родителя под Windows
   (управление телефоном и ПК ребёнка, экран, чат, карта, архив
    сайтов и программ в SQLite, системный трей и уведомления).
3. build_windows_exes.bat      — автоматический сборщик готовых .exe
4. run_parent_windows.bat      — быстрый запуск программы родителя

--------------------------------------------------------------------
КАК ПОЛУЧИТЬ ГОТОВЫЕ .EXE ФАЙЛЫ НА WINDOWS (2 СПОСОБА)
--------------------------------------------------------------------

СПОСОБ 1 — В ОДИН КЛИК НА ВАШЕМ WINDOWS (1–2 минуты):
1. Распакуйте весь архив KidsGuard-Windows-Pack.zip в любую папку
   (например, C:\KidsGuard).
2. Дважды нажмите на файл:  build_windows_exes.bat
3. Скрипт сам проверит Python (если его нет — автоматически установит
   Python 3.12 через встроенный Windows winget), поставит библиотеки
   и соберёт два автономных .exe файла в папке dist\:
     • dist\hosts_blocker.exe     — агент на компьютер ребёнка
     • dist\KidsGuardParent.exe   — программа родителя на ваш ПК
4. После сборки папка dist\ откроется автоматически.

СПОСОБ 2 — ГОТОВЫЕ .EXE БЕЗ УСТАНОВКИ PYTHON (через GitHub Actions):
Если вы синхронизировали проект с GitHub:
1. Откройте ваш репозиторий на GitHub -> вкладка "Actions" (или "Releases").
2. Откройте последний запуск "Build KidsGuard APK & Windows EXEs".
3. В разделе Artifacts скачайте уже собранные:
     • KidsGuard-PC-Agent         (внутри готовый hosts_blocker.exe)
     • KidsGuard-Parent-Windows   (внутри готовый KidsGuardParent.exe)
     • KidsGuard-debug-apk        (готовый Android APK)

--------------------------------------------------------------------
КАК УСТАНОВИТЬ И ЗАПУСТИТЬ
--------------------------------------------------------------------

На компьютере РЕБЁНКА (hosts_blocker.exe):
• При первом запуске нажмите правой кнопкой -> "Запуск от имени администратора".
• Агент установит себя в систему, настроит автозапуск и выдаст код сопряжения
  (по умолчанию 101-701), который нужно ввести в приложении родителя.

На компьютере РОДИТЕЛЯ (KidsGuardParent.exe):
• Просто запустите KidsGuardParent.exe двойным кликом (права администратора не нужны).
• Укажите код телефона ребёнка и код ПК ребёнка — все логи, программы
  и посещённые сайты будут сохраняться в локальный архив на диске,
  даже когда компьютер ребёнка выключен.
